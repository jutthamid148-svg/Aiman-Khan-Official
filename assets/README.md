# Aiman Khan Official — image assets

The page uses the temporary source registry in `asset-manifest.js` so image references stay centralized.

To replace a placeholder, add the creator-approved file to the matching directory and update only the relevant value in `asset-manifest.js`.

- `logo/` — brand mark and favicon
- `hero/` — primary cinematic portrait
- `about/` — about-section portrait
- `videos/` — YouTube thumbnails
- `gallery/` — Instagram-style lifestyle images

Prefer WebP or AVIF images sized for their rendered use. Do not use third-party photography in the final production site without permission.
